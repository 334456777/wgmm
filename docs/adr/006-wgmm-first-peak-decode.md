# ADR 006: 采用首峰解码替代全局峰值（WGMM 峰值预测结构修正）

## 状态

已采纳 (Accepted)

## 日期

2026-06-06

## 背景 (Context)

### 问题

WGMM 的 `scan_future_peak` 在未来 15 天视野内扫描 `score(t)` 曲线时，取**全局最佳峰值**（`argmax`）作为"下一次发布"的预测时刻。
但从数学上，季节强度在多模态/周期信号上的全局众数**不是「下一到达时间」该有的数学对象**——它系统性偏远。

对 `data/mtime.txt`（408 行 → 经 `aggregate_publish_events(600s)` 折成 223 个发布事件，跨度 702 天）的
walk-forward 验证表明，全局峰值的 baseline 误差为：

| 模式 | MAE (h) | RMSE (h) | MedAE (h) | 多 seed MAE |
|---|---:|---:|---:|---|
| expanding（N=80） | 168.7 | 218.5 | 151.1 | — |
| sliding（N=80，W=80） | 152.0 | 192.2 | 139.2 | — |
| expanding（12 seeds） | — | — | — | 158.9 ± 7.7 |

MedAE 高达 ≈140–151 h（≈6 天），说明全局峰几乎总是落在远处。

### 研究过程

对 WGMM 的四个结构性假设缺口（序列顺序、分布平稳、维度可加、全局带宽）逐一提出候选改进机制，
用真实源码（直接 import `wgmm_monitor.wgmm.*`）作为 baseline，在随机化 walk-forward 下量化每个机制的预测增益。

## 决策 (Decision)

**将 `scan_future_peak` 的峰值选择从「全局最佳峰」改为「视野内首个显著峰」（得分 > 扫描均值的第一个 raw peak），无显著峰时退回得分最高的 raw peak。**

同时，**不采纳**其余候选机制（序列依赖、非平稳 EWMA、多尺度联合、局部自适应带宽），原因见下文。

## 理由 (Rationale)

### 1. 核心改进：首峰解码（−57% MAE）

**数学动机**：任意时间点过程的预测都可分解为「周期内何时（相位/季节强度）」与「距上次多久（等待时间分布）」。
WGMM 只建了前者。预测「下一次发布」对应的数学对象是等待时间分布的中心，或等价地是 `score(t)` 的**首个（最近）模态**，
而非全局模态。全局众数在多模态/周期信号上系统性偏远。

这一判断对**任何含周期性/多模态的发布序列**都成立——只要 15 天里出现 ≥2 个模态，全局 argmax 就可能不是最近那个。

**验证结果**（expanding N=80, seed=42）：

| 口径 | 改前·全局峰 | 改后·首峰 | ΔMAE |
|---|---|---|---|
| expanding N=80 s42 | 168.7 / 218.5 / 151.1 | **73.2 / 152.2 / 23.8** | −95.5 (−56.6%) |
| sliding N=80 s42 | 152.0 / 192.2 / 139.2 | **61.3 / 108.1 / 21.7** | −90.7 (−59.7%) |
| 全切分点 N=145 | 159.4 / 206.7 / 145.5 | **67.3 / 133.5 / 22.1** | −92.1 (−57.8%) |
| 16-seed expanding | 158.2 ± 6.9 | **68.2 ± 8.3** | −90.0 |
| 16-seed sliding | 140.6 ± 6.0 | **68.0 ± 7.1** | −72.6 |

三项度量（MAE / RMSE / MedAE）全部下降、无任何退化，增益（−90h）远超 seed 噪声（±8h）。

### 2. 被拒绝的候选机制

#### 2a. 序列依赖（K 阶条件间隔核回归）— 放弃

净边际增益仅 −1.9 h（−2.9%），落在 seed 噪声内。
根本原因：相邻间隔互信息 `I(Δt_k; Δt_{k−1}) ≈ 0.09–0.17 nats`，仅占 `H(Δt)=2.47 nats` 的 3.5–6.9%——
序列历史本身可供利用的信息就这么少。这是一条可推广判据：对新数据先测互信息，>~15% 才值得上序列模型。

#### 2b. 非平稳（EWMA recency 加权 cadence）— 放弃

报告建议「弱并入」，但生产验证中 A/B 对比显示 ΔMAE = +0.0h、ΔRMSE = +0.0h——零影响。
原因是 `pos_lambda=0.0015`（每小时）过于激进，超过几周的历史事件权重衰减至 ≈0，实际效果退化为只看最近少数事件。
报告声称的 −3% RMSE 也在 seed 噪声（±8.8h）内。按「Simple is Better」原则，不保留无实际收益的复杂度。

#### 2c. 多尺度联合（hour×wday 联合核）— 放弃

联合核 90.7h / 可加 93.0h vs 公平基线 67.3h，**更差 +35~38%**。
季节相位整体就被等待时间项压制；在被压制的分量里再细抠维度交互，改善的是次要误差源。

#### 2d. 局部自适应带宽（kNN 局部 σ）— 放弃

净 ΔMAE = −0.0 (−0.1%)，无任何改善。在 ~223 事件的典型样本量下，全局自适应 σ 已足够。

### 3. 一句话总结

**真正的杠杆只有一处结构缺口（全局峰 ≠ 首峰），其余是装饰。** 核心修正把 MAE 从 159h 砸到 67h；
之后再叠加任何「高级」机制，最多再动 0–3h，而多 seed 噪声本身就有 ±8.8h。

## 后果 (Consequences)

### 正面影响

1. **MAE 从 ≈159h 降至 ≈67h（−57%）**：预测准确性大幅提升。
2. **MedAE 从 ≈145h 降至 ≈22h（−85%）**：中位预测从偏差 6 天改善到不足 1 天。
3. **代码更简洁**：新逻辑比旧逻辑少 8 行，去掉了 `score_std`、`peak_score_threshold`、`gradient_threshold` 等中间变量。
4. **接口不变**：`scan_future_peak` 的签名与返回值完全不变，对上层 `decide_next_frequency` 透明。

### 负面影响

1. **极端间隔仍存在**：walk-forward 中有一个 1131h 的异常预测（训练集仅 96 个事件时），但全局峰值下同一位置的误差更大。
2. **理论上可能跳过近距离峰值**：如果近期的真实发布恰好落在低分时段（score < scan_mean），首峰会跳到下一个显著峰。
   但 scan_mean 是全视野均值，低分时段通常不会产生显著的 raw peak，因此实际风险很低。

### 权衡结论

MAE −57% / MedAE −85% 的确定性增益远超潜在的边缘风险。代码改动仅限 `scan_future_peak` 内部 20 行，
不影响外部接口，可独立 revert。

### 可预测性上限（信息论标尺）

序列对数间隔互信息：

```
I(Δt_k; Δt_{k−1}) ≈ 0.09–0.17 nats，仅占 H(Δt)=2.47 nats 的 3.5–6.9%
```

这条标尺解释了所有「高级」机制增益为何如此小：序列历史本身可供利用的信息就这么多。
对新数据应先测互信息，>~15% 才值得上序列/非平稳模型。
