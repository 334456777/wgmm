# ADR 007: 维持 WGMM 结构现状（第二轮建模改进研究：无剩余结构性增益）

## 状态

已采纳 (Accepted)

## 日期

2026-06-10

## 背景 (Context)

### 问题

ADR 006 落地首峰解码（MAE −57%）后，WGMM 仍存在若干**未检验的结构性假设缺口**：
得分函数 s(t) 不是"下一次到达时间"的概率密度（无法做 L1 最优解码与区间预测）、
无显式等待时间/更新过程项、维度加性组合、事件袋装（丢序列顺序）、
启发式（非似然驱动）的 λ/ω/σ 学习、单一指数遗忘表达非平稳。
第二轮研究的问题是：**在首峰解码之后，这些缺口里还有没有可变现的预测增益？**

### 研究过程

以仓库真实源码为 baseline（直接 `import wgmm_monitor.wgmm.*`，含 ADR 006 首峰解码），
对 `data/mtime.txt` 快照（408 行 → 去重 306 → 600s 聚合 **223 个发布事件**，跨度 702 天）
做随机化 walk-forward 交叉验证：N=40 随机切分点（k 落在序列 30%–95%）×
expanding/sliding 双模式 × 3 个 seed（42/7/123），每口径 995 次"下一次发布时间"预测，
误差单位小时。候选机制共 12 个，覆盖概率化重构、泊松首达解码、序列依赖、
非平稳衰减、多尺度联合核、自适应带宽六个方向。

## 决策 (Decision)

**不并入任何候选建模机制——WGMM 算法层零代码变更。**

同时采纳两项方法论产出：

1. **泊松首达重释**（把 s(t) 标定为非齐次泊松强度、取生存函数中位数解码）记录为
   "RMSE 取向"的现成备选：MAE +3% 换 RMSE −8%（6 个 run 全部一致）。仅当未来调度
   损失更接近 RMSE（极端漏检代价高）时启用。
2. **新数据预检清单**（见"理由 4"）作为后续在其它 UP 主数据上评估改进的标准流程。

## 理由 (Rationale)

### 1. baseline 已贴住无条件 L1 下界

测试集上"事后最优常数预测器"（恒预测测试间隔中位数 30.5h）的 MAE = **67.35h**；
WGMM baseline = **67.83h**（差 0.7%）。任何点预测模型在 L1 意义上的改进空间最多 0.5h，
而 seed 间噪声就有 ±1.9h。

| 口径 | baseline MAE ± std (h) | RMSE (h) | MedAE (h) |
|---|---:|---:|---:|
| expanding（N=40, seed 42） | 67.92 ± 26.79 | 122.62 ± 60.20 | 22.71 |
| sliding（N=40, W=60, seed 42） | 69.18 ± 26.56 | 123.42 ± 59.49 | 24.04 |
| expanding 三 seed | 67.9 / 66.8 / 64.2 | — | — |

### 2. 信息论增益预算：可利用的条件信息 ≲5%

六分位离散下 I(Δtₖ; Δtₖ₋₁) = 0.054 bits，仅占边缘熵 2.585 bits 的 **2.1%**，
循环移位代理检验 p=0.94——相邻间隔统计上不可区分于独立；
日历信息 I(Δt; 锚点 4h 时段) = 0.083 bits（3.2%，p=0.0485，边缘显著）。
两者合计 ≲5% 边缘熵，即使完美变现也只有个位数百分比的 MAE 改善——
恰好落在 seed 噪声带内。这与 ADR 006 第一轮的独立估计
（0.09–0.17 nats / 2.47 nats ≈ 3.5–6.9%）同量级，结论封闭：**不是实现不好，而是信息不存在**。

### 3. 分层归因：日历结构的价值真实存在，但被重尾精确抵消

按目标间隔分层（expanding，995 预测）：baseline 在短间隔段（<24h，占 43%）
误差 10.9h vs 无条件中位数 18.6h（**−40%**，首峰解码的爆发跟随能力）；
但长于中位数的间隔贡献 **91% 的总误差质量**，各候选机制只能在分段之间搬运误差，
而"下一个间隔属于哪段"正是 MI≈0 所证明的不可知信息。

诊断阶梯同时证明 **s(t) 在结构上不是到达密度**：直接对 s(t) 取质量中位数解码，
15 天视野 MAE +103%、45 天视野 +588%（准平稳周期信号的中位数落在视野中部）；
补上更新结构（×间隔 KDE 或纯间隔 KDE）后立即恢复 baseline 水平——
**ADR 006 的首峰解码已经是更新先验的正确轻量等价物**
（刚发生事件自身的核在 now 附近抬高得分，首峰天然落在近处）。

### 4. 可推广预检清单（对任意新发布序列，跑改进之前先算四个数）

1. 间隔 CV 与长尾误差占比（CV≳2、尾部占比 >~70% ⇒ L1 被尾部锁死，条件机制空间极小）；
2. 带循环移位代理检验的 I(Δtₖ; Δtₖ₋₁)（占比 <~15% 或 p>0.05 ⇒ 不上序列模型）；
3. expanding vs sliding 的 baseline 对照（sliding 不优 ⇒ 不上非平稳机制）；
4. baseline MAE 与"事后最优常数"下界的距离（<5% ⇒ 只剩误差形状可调，考虑泊松首达换 RMSE）。

## 后果 (Consequences)

### 正面影响

1. **零代码变更、零新增复杂度**：与"Simple is Better"一致，避免为 ≤0.5h 的理论空间引入
   KDE/条件核/联合核等维护负担。
2. **ADR 006 的四项"放弃"结论获得独立复证**（不同实现、不同切分协议、多 seed）。
3. **形成判据资产**：L1 下界对照、MI 代理检验、expanding/sliding 漂移检测、
   增益预算论证，可直接复用于其它创作者数据。
4. **保留一条现成的 RMSE 取向出路**（泊松首达解码），未来需求变化时无需重新研究。

### 负面影响

1. 结论基于单一创作者样本（监控场景天然如此）；其它行为模式的 UP 主需先过预检清单。
2. 泊松首达选项未并入代码，启用时需按归档脚本重新实现（约 20 行）。

### 权衡结论

L1 改进空间（≤0.7%）远小于任何候选机制的实现与维护成本；
维持现状是数学上和工程上的双重最优。
